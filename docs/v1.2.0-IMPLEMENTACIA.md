## Rozhodnutia z analýzy

| Téma | Rozhodnutie |
| --- | --- |
| Povinnosť účtu | Povinný pre všetkých — bez prihlásenia sa nedá založiť stôl ani pripojiť |
| Overenie e-mailu | Povinné — bez kliknutia na odkaz sa nedá hrať; dá sa poslať znova aj opraviť e-mail |
| Odosielanie e-mailov | Gmail SMTP (App Password) cez sidecar kontajner; hra ostáva bez prístupu na internet |
| Prihlásenie | E-mail alebo hráčske meno + heslo; token v localStorage → socket.io `auth.token`; 180 dní |
| Hráčske meno | Jedno pre všetky stoly, jedinečné bez ohľadu na veľkosť písmen, 3–20 znakov, bez @ |
| Heslo | 8–128 znakov, zadáva sa 2×; `scrypt` (node:crypto, bez nových závislostí) |
| Iné zariadenie pri tom istom stole | Staré zariadenie server od stola odpojí → lobby s hláškou; účet ostáva prihlásený |
| Iný stôl na inom zariadení | Povolené |
| Peniaze | Každý stôl má vlastný stack/ledger ako doteraz — účet peniaze neprenáša |
| Štatistiky | Pri stole (leaderboard) + globálne v profile: ruky, výhry, % výhier, najväčší pot, výsledok podľa meny, zoznam stolov |
| Staré stoly | Zálohované, len na čítanie („Moje stoly → Archív“), dajú sa prevziať do účtu (počítajú sa do štatistík) |
| Fotka | Komprimovaná v prehliadači na 256 px WebP/JPEG (≤ 150 kB); nahrádza emoji všade; dá sa zmazať |
| Zlúčenie hráčov (v1.1.0) | Pri stoloch s účtami netreba — vypnuté |
